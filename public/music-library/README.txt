Put your MP3/MP4 files in this folder.

Then update:
src/musicLibraryData.js

Example:
{
  id: "my-song",
  title: "My Song",
  artist: "Artist Name",
  type: "audio",
  src: "/music-library/my-song.mp3"
}

For video:
{
  id: "my-video",
  title: "My Video",
  artist: "Artist Name",
  type: "video",
  src: "/music-library/my-video.mp4"
}
