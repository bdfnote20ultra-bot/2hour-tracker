Put MP3/MP4 files in this folder.

Then update src/musicLibraryData.js.

Example audio entry:
{
  id: "my-song",
  title: "My Song",
  artist: "Artist Name",
  type: "audio",
  src: "/music-library/my-song.mp3"
}

Example video entry:
{
  id: "my-video",
  title: "My Video",
  artist: "Artist Name",
  type: "video",
  src: "/music-library/my-video.mp4"
}
